# 🖨️ 即印即玩 (Print & Play) 規格與製作指南

本資料夾用於存放可用於實體列印的排版成品或 PDF/圖片樣品。

---

## 📐 標準尺寸建議 (Standard Sizing)

| 配件名稱 | 國際標準規格 | 建議紙質與克重 |
| :--- | :--- | :--- |
| **標準卡牌 (Poker Size)** | 63 mm × 88 mm (2.5" × 3.5") | 250g ~ 300g 銅西卡，或使用標準卡套加一般紙夾底 |
| **小卡 / 迷你卡 (Mini Euro)** | 44 mm × 68 mm | 適合事件卡、資源卡、隱藏目標卡 |
| **玩家圖板 (Player Board)** | A5 (148 mm × 210 mm) | 350g 厚灰紙板裱貼 |
| **中央主圖板 (Main Board)** | A3 (297 mm × 420 mm) 或 2片 A4 拼接 | 2mm 灰紙板裱紙雙折 |
| **指示物 / 標記 (Tokens)** | 直徑 15mm ~ 25mm 圓形 / 正方形 | 2mm 荷蘭灰卡手工沖孔或雷射切割 |

## ✂️ 快速手工打樣技巧 (Rapid Prototyping Tips)

1. **便宜卡套夾底法（最推薦！）**：
   - 購買一包便宜的「63x88mm 透明卡套」（一包 100 張約幾十元台幣）。
   - 準備廢棄的舊卡牌（例如舊撲克牌、魔法風雲會廢卡、遊戲王廢卡）。
   - 將列印好的普通 A4 紙剪裁後，與廢卡一同塞入透明卡套，手感與硬度即可達到商用等級！
2. **出血位 (Bleed Area)**：
   - 裁切會有誤差，排版時每邊至少保留 2~3mm 的邊界空間，避免裁切時切到文字。
3. **對齊輔助**：
   - 在排版四角放置「十字裁切線 (Crop Marks)」，裁切時用鋼尺與美工刀劃過對位最準確。
